## 🎮 ゲーム概要
可愛い白猫ちゃん（＆おにぎり勇者）が、街の広場を独占して贅沢三昧するお騒がせボスねこたちを懲らしめる、全8ステージの本格2D横スクロールアクションゲームです！

- **ブラウザですぐに遊べる！**（インストール不要・PCキーボード操作推奨）
- **選べる2大主人公！**（白ねこ ＆ おにぎり）
- **全8大ステージ ＆ 8大個性派ボスねこ！**
- **全曲オリジナル・本格BGM＆ダイナミックSE！**
- **全国オンラインランキング対応！**（ハイスコアを競い合おう！）

## 🕹️ 操作方法（PCキーボード）

| アクション | 操作キー | 詳細 |
| :--- | :--- | :--- |
| **いどう** | `←` / `→`（または `A` / `D`） | てくてく走る（ブレーキ演出あり） |
| **ジャンプ** | `Space`（または `↑` / `W`） | 快適ジャンプ！ 敵を踏みつけると大バウンド！ |
| **こうげき** | `Z`（または `J` / `Enter`） | 【ねこ】ひっかき爪攻撃 / 【おにぎり】特製梅干しショット |
| **ひっさつわざ** | `Z` 長押し ➔ 離す | ロックマン式極大チャージ！ 画面いっぱいの超威力を放つ！ |

## 🌟 主人公キャラクター紹介
- **🐾 白ねこ**:
  - 移動と跳躍のバランスが良いスタンダード勇者。
  - 近接のひっかき爪攻撃と、踏みつけバウンドで敵をテンポよく撃破！
  - チャージ必殺技: **『極大・超ねこ波動拳』**
- **🍙 おにぎり**:
  - コロコロ転がりながらジャンプする愛くるしい勇者。
  - 遠距離からポイポイ投げられる梅干しショットで安全に敵を狙い撃ち！
  - チャージ必殺技: **『超巨大・特製梅干しボム』**
